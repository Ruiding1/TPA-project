Temporal Prototype Alignment

for Frozen-Feature Dataset Distillation

Rui Ding1, Jin Hu1, Mei Chen1, Xi Wu1, Fan Wu2, Kehua Guo2,*, Tao Gu3

1 Chengdu University of Information Technology2 Central South University3 Macquarie University

View poster ↗Release status

Distill a compact image set by reusing gradient evidence across time. TPA builds temporal prototypes from frozen teachers, then aligns synthetic images within each teacher’s feature space.

01 / Method

One fresh view. A running prototype.

Spatial multi-view matching

Multiple augmented views are processed at the same step to stabilize gradient targets. Keeping concurrent views increases memory and computation.

Temporal prototype alignment

TPA uses one fresh view per step and accumulates real-gradient statistics over time. Fixed-size moment buffers retain the history used to guide synthesis.

Adaptive Temporal Momentum ATM

A reliability-dependent gate balances incoming gradients with the accumulated history. First and second moments form an inverse-RMS-weighted prototype. Initialization-mass correction accounts for zero-initialized moments.

Contrastive Consensus Alignment CCA

Each teacher compares class-wise synthetic gradients with its own real prototypes. Matched classes are positives and other classes are negatives. The teacher-local losses optimize one shared synthetic image set without requiring equal feature dimensions.

Memory and synthesis time

For the reported CLIP ImageNet-100 IPC=1 setting, peak memory changes from 81 GB to 7 GB and distillation time from 3.6 h to 0.8 h, with accuracy changing from 84.9% to 86.7%.

The reported LGM run uses 4 × RTX 4090 and TPA uses 1 × RTX 4090. These measurements are not a same-hardware speedup comparison.
