Temporal Prototype Alignment

for Frozen-Feature Dataset Distillation

Reuse gradient evidence across time.
Distill images that transfer across encoders.

The idea

A small image set.
A richer learning signal.

Dataset distillation compresses a large training set into a small synthetic set. With frozen vision encoders, the challenge is to preserve useful class information while keeping synthesis affordable—and to transfer that information to models beyond those used for synthesis.

TPA changes where the evidence comes from. Rather than constructing a gradient target from many simultaneous augmented views, it accumulates real-gradient statistics over optimization steps. Synthetic images then match the resulting class prototypes through a contrastive objective within each teacher.

This couples temporal reuse with multi-teacher class alignment: a compact history supplies the target, and several frozen teachers shape one shared set of pixels.

Adaptive Temporal Momentum (ATM) retains useful history in a class-wise gradient prototype. It replaces repeated concurrent views with statistics accumulated during synthesis.

One shared synthetic image set

Contrastive Consensus Alignment (CCA) matches same-class gradient pairs and separates different classes. Each teacher works in its own feature space; their losses jointly update the synthetic pixels.

1

Collect comparable gradients

At each step, real and synthetic images use the same freshly initialized classifier head on top of a frozen encoder. Class-wise classifier gradients provide the representation to match.

2

Build a temporal prototype

ATM gates the first-moment update using gradient reliability and tracks a fixed-decay second moment. Inverse-RMS weighting forms the prototype; initialization-mass correction accounts for zero-initialized moments.

3

Optimize through class alignment

Within each teacher, synthetic class gradients are compared with real class prototypes. Same-class pairs are positives; other classes are negatives. Summed teacher-local losses update a common image set.

Why independent teacher spaces work: each teacher produces class-to-class alignment scores in its own feature coordinates. Combining the losses does not require equal feature dimensions or direct alignment between teacher embeddings.
