# Temporal Prototype Alignment — Project Page

Project website for **Temporal Prototype Alignment for Frozen-Feature Dataset Distillation**, NeurIPS 2026.

[Project page](https://ruiding1.github.io/TPA-project/) · [Paper](https://ruiding1.github.io/TPA-project/assets/TPA-paper.pdf) · [Poster](https://ruiding1.github.io/TPA-project/assets/TPA-poster.pdf)

## Contents

The page presents the ATM and CCA mechanisms, comparisons with spatial multi-view matching, transfer results across nine target encoders, synthesis efficiency, and synthetic-image galleries.

- `index.html`: paper overview, method, results, galleries, and resource links.
- `style.css`: responsive layout and typography.
- `script.js`: interactive gallery controls.
- `assets/`: paper and poster PDFs, vector method and result figures, and synthetic-image grids.

Open `index.html` in a browser to view the page locally. GitHub Pages serves the site from the `main` branch. The project URL is also the destination of the poster QR code.

## Figures and results

Figures and numerical results correspond to the paper. The efficiency comparison uses four RTX 4090 GPUs for LGM and one RTX 4090 for TPA. The poster is landscape, 1400 × 900 mm.

## Availability

The paper, poster, and project-page assets are publicly available. The implementation, synthetic datasets, and raw evaluation records remain private.
